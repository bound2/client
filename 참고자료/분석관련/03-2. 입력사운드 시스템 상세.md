## 1. 입력 시스템 (`CDirectInput` / `CSDLInput`)

### 1-1. 클래스 구조

```cpp
class CDirectInput {
    BYTE  m_key[256];           // 현재 프레임 키 상태 (SDL 스캔코드 인덱스)
    int   m_MouseX, m_MouseY;   // 마우스 좌표
    int   m_MouseZ;             // 마우스 휠 (누적값)
    BYTE  m_MouseButtonDown[3]; // 버튼 눌림 이벤트 (단일 프레임)
    BYTE  m_MouseButtonUp[3];   // 버튼 뗌 이벤트 (단일 프레임)
    BYTE  m_MouseButton[3];     // 버튼 현재 상태 (지속)

    // 이벤트 콜백 함수 포인터
    void (*m_pMouseCallback)(E_MOUSE_EVENT, int, int, int);
    void (*m_pKeyboardCallback)(E_KEYBOARD_EVENT, UINT, UINT);
};
```

### 1-2. 이벤트 열거형

```cpp
enum E_MOUSE_EVENT {
    MOUSE_LBUTTON_DOWN, MOUSE_LBUTTON_UP,
    MOUSE_RBUTTON_DOWN, MOUSE_RBUTTON_UP,
    MOUSE_MBUTTON_DOWN, MOUSE_MBUTTON_UP,
    MOUSE_MOVE, MOUSE_WHEEL
};

enum E_KEYBOARD_EVENT {
    KEYBOARD_DOWN,
    KEYBOARD_UP
};
```

### 1-3. SDL 이벤트 펌프 (`dxlib_input_update`)

매 프레임 게임 루프에서 호출되며 SDL 이벤트 큐를 처리:

```
SDL_PollEvent() 루프
├── SDL_QUIT              → g_quit_flag = true
├── SDL_KEYDOWN           → m_key[scancode] = 1, KeyboardCallback(DOWN)
├── SDL_KEYUP             → m_key[scancode] = 0, KeyboardCallback(UP)
├── SDL_MOUSEMOTION       → m_MouseX/Y 갱신, MouseCallback(MOVE)
├── SDL_MOUSEBUTTONDOWN   → m_MouseButton/Down[btn] 갱신, MouseCallback(DOWN)
├── SDL_MOUSEBUTTONUP     → m_MouseButton/Up[btn] 갱신, MouseCallback(UP)
├── SDL_MOUSEWHEEL        → m_MouseZ += delta, MouseCallback(WHEEL)
└── SDL_TEXTINPUT         → InputFocusManager::getInstance().handleTextInput()
    SDL_TEXTEDITING       → InputFocusManager::getInstance().handleTextEditing()
```

### 1-4. 이중 키 코드 시스템

#### `KEYCODE_*` (신규, `basic/InputCodes.h`)

SDL 스캔코드 값을 직접 사용하는 새로운 상수 체계:

```cpp
// 예시 (SDL_SCANCODE_* 값과 동일)
#define KEYCODE_A         0x04
#define KEYCODE_F1        0x3A
#define KEYCODE_ESCAPE    0x29
#define KEYCODE_LSHIFT    0xE1
#define KEYCODE_RETURN    0x28
```

범위: `0x04` (A) ~ `0xE4` (RCTRL), 총 약 100여 개 정의

#### `DIK_*` (레거시, 하위 호환용)

DirectInput 키 코드를 SDL 스캔코드로 매핑하는 정적 변환 테이블:

```cpp
// DXLibBackendSDL.cpp
static SDL_Scancode g_dik_to_scancode[256];

void init_key_mapping() {
    g_dik_to_scancode[DIK_ESCAPE] = SDL_SCANCODE_ESCAPE;  // 0x01
    g_dik_to_scancode[DIK_1]      = SDL_SCANCODE_1;       // 0x02
    g_dik_to_scancode[DIK_A]      = SDL_SCANCODE_A;       // 0x1E
    // ... 전체 매핑 테이블
}
```

`m_key[256]`은 SDL 스캔코드 인덱스로 접근하므로, 기존 `DIK_*` 코드를 쓰는 코드는 `g_dik_to_scancode[]`를 통해 변환 후 조회.

### 1-5. 한글 IME 처리

```
SDL_TEXTINPUT / SDL_TEXTEDITING 이벤트
    → InputFocusManager::handleTextInput(text)
    → InputFocusManager::handleTextEditing(text, start, length)
```

`InputFocusManager`는 현재 포커스를 가진 입력 위젯에 이벤트를 전달. `CI_KOREAN` / `CI_CHINESE` 클래스가 자모 조합 상태를 관리 (별도 분석 참조).

### 1-6. 콜백 등록 방식

```cpp
g_pInput->SetMouseCallback(MyMouseHandler);
g_pInput->SetKeyboardCallback(MyKeyHandler);
```

콜백은 이벤트 즉시 호출되며, `m_key[]` 상태 배열과 병행 사용 가능.

## 2. 효과음 시스템 (`CDirectSound` / `CSDLAudio`)

### 2-1. 클래스 구조

```cpp
class CDirectSound {
    LPDIRECTSOUNDBUFFER Create(LPSTR filename, int nMaxCount);
    void Play(LPDIRECTSOUNDBUFFER, bool loop=false);
    void Stop(LPDIRECTSOUNDBUFFER);
    void SetVolume(LPDIRECTSOUNDBUFFER, long vol);    // -10000 ~ 0 dB
    void SetPan(LPDIRECTSOUNDBUFFER, long pan);       // -10000 ~ 10000
    void SetFrequency(LPDIRECTSOUNDBUFFER, long freq);
    void SetMute(LPDIRECTSOUNDBUFFER, bool mute);
    LPDIRECTSOUNDBUFFER Duplicate(LPDIRECTSOUNDBUFFER);
    bool IsPlaying(LPDIRECTSOUNDBUFFER);
};
```

`LPDIRECTSOUNDBUFFER`는 내부적으로 `dxlib_sound_buffer*` 포인터 (void* 캐스팅):

```cpp
struct dxlib_sound_buffer {
    Mix_Chunk* chunk;       // SDL_mixer 오디오 데이터
    int        channel;     // 재생 중인 SDL 채널 번호 (-1 = 미재생)
    int        volume;      // 현재 볼륨 (0-128, MIX_MAX_VOLUME)
    int        pan_left;    // 왼쪽 패닝 값 (0-255)
    int        pan_right;   // 오른쪽 패닝 값 (0-255)
    bool       playing;     // 재생 상태 플래그
};
```

### 2-2. 초기화

```cpp
// dxlib_sound_init()
Mix_OpenAudio(44100, MIX_DEFAULT_FORMAT, 2, 1024);
Mix_AllocateChannels(32);  // 동시 재생 채널 수
```

- 샘플레이트: 44100 Hz
- 포맷: SDL_mixer 기본 (보통 S16 리틀엔디언)
- 채널: 스테레오 (2ch)
- 버퍼: 1024 샘플

### 2-3. 사운드 버퍼 생성

```cpp
// dxlib_sound_create(filename, nMaxCount)
Mix_Chunk* chunk = Mix_LoadWAV(filename);
// nMaxCount: 동시 재생 가능 복사본 수 (Duplicate 기반)
```

### 2-4. 재생 제어

| 함수 | 구현 |
|------|------|
| `Play(buf, loop)` | `Mix_PlayChannel(-1, chunk, loop?-1:0)` → channel 저장 |
| `Stop(buf)` | `Mix_HaltChannel(channel)` |
| `IsPlaying(buf)` | `Mix_Playing(channel)` |
| `Duplicate(buf)` | 새 `dxlib_sound_buffer` 생성, 동일 `Mix_Chunk*` 공유 |

### 2-5. 볼륨/패닝

```cpp
// 볼륨: DirectSound dB(-10000~0) → SDL(0~128) 변환
void SetVolume(buf, long vol) {
    // vol = 0(최대) ~ -10000(무음)
    int sdl_vol = (int)((vol + 10000) * MIX_MAX_VOLUME / 10000);
    Mix_VolumeChunk(buf->chunk, sdl_vol);
}

// 패닝: DirectSound(-10000~10000) → SDL_mixer SetPanning(0-255)
void SetPan(buf, long pan) {
    // pan = -10000(좌) ~ 10000(우)
    buf->pan_left  = (int)((10000 - pan) * 255 / 20000);
    buf->pan_right = (int)((10000 + pan) * 255 / 20000);
    Mix_SetPanning(buf->channel, buf->pan_left, buf->pan_right);
}
```

### 2-6. 미지원 기능 (스텁)

```cpp
void SetFrequency(buf, long freq) {
    // SDL_mixer는 채널별 주파수 변경 미지원 → 무시
}
```

## 3. 배경음악 시스템 (`CDirectMusic` / `CSDLMusic`)

### 3-1. 클래스 구조

```cpp
class CDirectMusic {
    bool Play(LPSTR filename, bool loop=true);
    void Stop();
    void Pause();
    void Resume();
    void SetVolume(long vol);
    void SetTempo(long tempo);           // 템포 제어 (BPM)
    bool IsPlaying();
    DIRECTMUSIC_TYPE GetType();          // HW / SW
};
```

```cpp
enum DIRECTMUSIC_TYPE {
    DIRECTMUSIC_HW,   // 하드웨어 (현재 SDL → SW로 처리)
    DIRECTMUSIC_SW    // 소프트웨어
};
```

### 3-2. 전역 상태

```cpp
// DXLibBackendSDL.cpp
static Mix_Music* g_current_music = nullptr;
static int        g_music_volume  = MIX_MAX_VOLUME;
static long       g_original_tempo;
static long       g_current_tempo;
```

동시에 하나의 음악 트랙만 재생 가능.

### 3-3. 지원 포맷

| 포맷 | 상태 |
|------|------|
| WAV | 지원 |
| OGG Vorbis | 지원 |
| MP3 | 지원 (SDL_mixer 빌드 옵션에 따라) |
| MIDI | 지원 (플랫폼 의존) |

### 3-4. 템포 제어

```cpp
void SetTempo(long tempo) {
    g_current_tempo = tempo;
    // SDL_mixer는 실시간 템포 변경 미지원 → 기록만 유지 (스텁)

```

### 3-5. 볼륨 제어

```cpp
void SetVolume(long vol) {
    // DirectMusic 볼륨 범위 → SDL 범위 변환
    int sdl_vol = (int)((vol + 10000) * MIX_MAX_VOLUME / 10000);
    Mix_VolumeMusic(sdl_vol);
}
```

## 4. 스트리밍 시스템 (`CDirectSoundStream` / `CSDLStream`)

### 4-1. 클래스 구조

```cpp
class CDirectSoundStream {
    bool Open(LPSTR filename);
    void Close();
    void Play(bool loop=false);
    void Stop();
    void Update();           // ← 게임 루프마다 반드시 호출
    void SetVolume(long vol);
    bool IsPlaying();
private:
    // 16개 알림(notification) 버퍼 슬롯
    // WAV RIFF 헤더 파싱
    // 버퍼 리필 로직
};
```

### 4-2. 스트리밍 구조

DirectSound 원본의 16-notification 링 버퍼 방식을 SDL_mixer Music으로 단순화:

```
Open(filename)
    → Mix_LoadMUS(filename)   // g_stream_music에 저장
Play()
    → Mix_PlayMusic(g_stream_music, loop?-1:0)
Update()
    → SDL_mixer가 내부적으로 스트리밍 처리
      (별도 콜백 불필요, Update()는 사실상 no-op)
```

WAV RIFF 헤더 파싱: `Open()` 내부에서 `fmt `, `data` 청크를 찾아 샘플레이트, 채널 수 추출 (SDL_mixer에 넘기기 위한 메타데이터).

### 4-3. 주의사항

- 원본 DirectSound 구현에서는 `Update()`가 필수(버퍼 리필)였으나 SDL_mixer 백엔드에서는 내부 처리로 대체됨
- 코드 호환성을 위해 `Update()` 호출은 유지되어야 함 (no-op이지만 호출 제거 시 포팅 이슈)
- `CSDLStream`은 내부적으로 `CSDLMusic`과 동일한 `Mix_Music*` 메커니즘 사용

## 5. 능력 감지 (`dxlib_get_capabilities`)

```cpp
uint32_t dxlib_get_capabilities() {
    uint32_t caps = 0;
    caps |= DXLIB_CAP_INPUT;    // 항상
    caps |= DXLIB_CAP_SOUND;    // SDL_mixer 초기화 성공 시
    caps |= DXLIB_CAP_MUSIC;    // SDL_mixer 초기화 성공 시
    caps |= DXLIB_CAP_STREAM;   // SDL_mixer 초기화 성공 시
    caps |= DXLIB_CAP_MP3;      // Mix_Init(MIX_INIT_MP3) 성공 시
    caps |= DXLIB_CAP_OGG;      // Mix_Init(MIX_INIT_OGG) 성공 시
    return caps;
}
```

## 10. 알려진 이슈 / TODO
