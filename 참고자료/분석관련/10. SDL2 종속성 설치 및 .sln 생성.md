## 남은 작업 (순서대로)

### 1단계: vcpkg 설치

```powershell
git clone https://github.com/microsoft/vcpkg.git C:\vcpkg
C:\vcpkg\bootstrap-vcpkg.bat
```

`vcpkg integrate install`은 선택사항 (VS IDE에서 자동 인식용). CMake로 직접 빌드할 거면 안 해도 되고, 나중에 VS2019에서 `.sln`을 열어 작업할 계획이면 해두는 게 편함.

### 2단계: 필수 패키지 설치 (x64-windows)

```powershell

아래 경로에서 실행 (고양집) 

cd H:\Source\GithubDesktop\vcpkg_download\vcpkg

vcpkg install sdl2:x64-windows
vcpkg install sdl2-image:x64-windows
vcpkg install sdl2-ttf:x64-windows
vcpkg install sdl2-mixer:x64-windows    # 사운드 (권장)
vcpkg install libiconv:x64-windows      # CMakeLists.txt가 iconv를 직접 링크함

# 한줄로 실행하는 방법 

cd H:\Source\GithubDesktop\vcpkg_download\vcpkg
.\vcpkg install sdl2:x64-windows sdl2-image:x64-windows sdl2-ttf:x64-windows sdl2-mixer:x64-windows libiconv:x64-windows




```

> `sdl2-ttf`가 freetype2를 소스에서 같이 빌드하기 때문에 이 단계가 제일 오래 걸림
 (패키지당 몇 분~수십 분, 인터넷 속도/CPU에 따라 다름). 
한 번에 몰아서 실행해두고 다른 일 하면서 기다리는 걸 추천.

### 3단계: 이전 실패한 configure 캐시 정리

vcpkg 툴체인 파일은 **처음 configure할 때** 지정해야 제대로 적용된다. 
지금 `build/vs2019/` 안에 vcpkg 없이 실패했던 캐시가 남아있으니 지우고 새로 시작:

```powershell
Remove-Item -Recurse -Force H:\Source\GithubDesktop\dk_client\build\vs2019
```

### 4단계: VS2019 솔루션 생성

```powershell
cd H:\Source\GithubDesktop\dk_client
  
cmake -S . -B build\vs2019 `
  -G "Visual Studio 16 2019" `
  -A x64 `
  -DCMAKE_TOOLCHAIN_FILE=H:\Source\GithubDesktop\vcpkg_download\vcpkg\scripts\buildsystems\vcpkg.cmake `
  -DCMAKE_BUILD_TYPE=Debug
  
  
```

성공하면 `build\vs2019\DarkEdenClient.sln`이 생성된다.

### 5단계: 빌드

```powershell
cmake --build build\vs2019 --config Debug
```

또는 `build\vs2019\DarkEdenClient.sln`을 VS2019에서 직접 열어서 빌드.

### 6단계: 링크 오류 나오면

`07. VS2019 마이그레이션 가이드.md`의 4절(예상 이슈 및 해결 방법)을 순서대로 확인. WinMain/th32 관련은 이미 고쳐놨으니, 남는 이슈가 있다면 대부분 iconv 링크 쪽(4-2)일 가능성이 높음 — vcpkg의 `libiconv` 임포트 라이브러리 이름이 CMakeLists.txt가 기대하는 `iconv`와 다를 수 있으니, 링크 오류 메시지에 나오는 실제 파일명을 확인해서 알려주면 그때 맞춰서 CMakeLists.txt를 고치면 됨.

## 참고: 왜 지금 당장 vcpkg를 안 깔았나

vcpkg 클론 + 부트스트랩 + SDL2 계열 빌드는 네트워크 다운로드와 소스 빌드가 껴서 시간이 꽤 걸리는 작업이라, 여기서 바로 진행하지 않고 직접 진행할 수 있게 절차만 정리해뒀다. 이 문서 순서대로 하다가 막히는 단계가 있으면 그 시점에 다시 이야기하면 됨.
