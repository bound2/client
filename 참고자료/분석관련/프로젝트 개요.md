# Dark Eden Client - 프로젝트 개요

> OpenDarkEden 클라이언트 오픈소스 재구현 프로젝트
> 원작: 한국 MMORPG "다크에덴" (Softon, 2000년대 초)

---

## 1. 프로젝트 기본 정보

- **장르**: 아이소메트릭 호러 MMORPG (디아블로 유사)
- **플레이어블 종족**: 슬레이어(인간) / 뱀파이어 / 아우스터
- **빌드 시스템**: CMake + Makefile 래퍼
- **언어**: C++ (Hungarian Notation, ~2000년대 원본)
- **플랫폼**: 원본 Windows → 현재 SDL2 기반 크로스플랫폼 이식 중

---

## 2. 디렉토리 구조

```
dk_client/
├── basic/          # 플랫폼 추상화 유틸리티
├── Client/         # 메인 게임 클라이언트
│   ├── DXLib/      # DirectX → SDL2 호환 레이어 (Input/Sound/Music)
│   ├── framelib/   # 프레임 애니메이션 시스템
│   ├── JpegLib/    # JPEG 라이브러리 헤더
│   ├── OtherClass/ # 패킷 팩토리 매니저
│   ├── Packet/     # 네트워크 패킷 정의
│   │   ├── Cpackets/  # CG* 클라이언트→서버 패킷
│   │   ├── Gpackets/  # GC* 서버→클라이언트 패킷
│   │   ├── Lpackets/  # LC/LG 로그인 패킷
│   │   ├── Rpackets/  # 요청 패킷
│   │   ├── Upackets/  # 업데이트 패킷
│   │   └── Types/     # 공통 타입 정의
│   ├── SpriteLib/  # 스프라이트 렌더링 (SDL2 백엔드)
│   ├── SXml/       # XML 파싱
│   ├── TextSystem/ # 텍스트 렌더링 (SDL2 + freetype2)
│   ├── Updater/    # 게임 업데이터
│   └── WinLib/     # Windows 레거시 레이어
├── VS_UI/          # UI 프레임워크
│   ├── src/        # UI 구현 (위젯, 다이얼로그, 스킨)
│   ├── widget/     # 버튼, 스크롤바, 에디터 위젯
│   ├── hangul/     # 한글 IME 입력 지원
│   └── Imm/        # 진동 피드백 라이브러리
├── tools/          # 개발 도구 (뷰어, 리소스 검증)
└── 분석관련/        # 분석 문서
```

## 4. 플랫폼 마이그레이션 현황

| 항목 | 원본 | 현재 | 상태 |
|------|------|------|------|
| 그래픽 | Direct3D | SDL2 | 완료 |
| 입력 | DirectInput | SDL2 | 완료 |
| 사운드 | DirectSound | SDL_mixer | 완료 |
| 음악 | DirectMusic | SDL_mixer | 완료 |
| 텍스트 | Windows GDI | SDL2 + freetype2 | 완료 |
| 플랫폼 추상화 | Win32 API | SDL2 + basic/ | 완료 |

- SDL2, SDL2_image, SDL2_ttf, SDL2_mixer
