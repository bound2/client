## 2. 스프라이트 클래스 계층 구조

```
[CSprite]  (추상, 기본 스프라이트)
├── CSprite555    파일 I/O 구현 (5:5:5 메모리 포맷)
└── CSprite565    파일 I/O 구현 (5:6:5 메모리 포맷)

[CAlphaSprite]  (추상, 픽셀별 알파채널 내장)
├── CAlphaSprite555
└── CAlphaSprite565

[CIndexSprite]  (추상, 팔레트 인덱스 기반 색상)
├── CIndexSprite555
└── CIndexSprite565

[CShadowSprite]   그림자 전용 스프라이트
[CSpritePal]      팔레트 적용 스프라이트
[CAlphaSpritePal] 팔레트 + 알파 스프라이트
```

### 스프라이트 타입별 용도

| 클래스 | 용도 | 포맷 |
|--------|------|------|
| `CSprite` | 타일, 배경 오브젝트, 아이템 | RGB565/555 |
| `CAlphaSprite` | 이펙트 (반투명) | RGBA4444 |
| `CIndexSprite` | 캐릭터 (색상 교체 지원) | Index + ColorSet |
| `CShadowSprite` | 그림자 | 4444 또는 소형 |
| `CSpritePal` | 이펙트 스크린 | Palette 기반 |

## 3. 픽셀 포맷 상세

### 저장 / 메모리 포맷

```
디스크 저장  : 항상 5:6:5 (RGB565)
메모리 보관  : 5:5:5 또는 5:6:5 (빌드 시 결정)
5:5:5 시스템 :
    파일(5:6:5) ──변환──> 메모리(5:5:5)
    메모리(5:5:5) ──역변환──> 파일(5:6:5)
```

### 포맷별 비트 구조

| 포맷 | 비트 구조 | 사용처 |
|------|----------|--------|
| RGB565 | R[15:11] G[10:5] B[4:0] | 타일, 배경, 메인 |
| RGB555 | R[14:10] G[9:5] B[4:0] | 호환성 변형 |
| RGBA4444 | A[15:12] R[11:8] G[7:4] B[3:0] | 이펙트 (반투명) |
| A1RGB555 | A[15] R[14:10] G[9:5] B[4:0] | 반투명 경계 |
| RGBA32 | A[31:24] B[23:16] G[15:8] R[7:0] | SDL 렌더링 캐시 |

### 픽셀 포맷 변환 코드 (SpriteLibBackendSDL.h)

```cpp
// RGB565 → 8비트 각 채널 추출
// 5비트 → 8비트: (v << 3) | (v >> 2)  ≈ v * 255/31
// 6비트 → 8비트: (v << 2) | (v >> 4)  ≈ v * 255/63
static inline void spritectl_565_to_rgb(uint16_t pixel,
                                         uint8_t* r, uint8_t* g, uint8_t* b) {
    uint8_t r5 = (pixel >> 11) & 0x1F;
    uint8_t g6 = (pixel >> 5)  & 0x3F;
    uint8_t b5 =  pixel        & 0x1F;
    *r = (r5 << 3) | (r5 >> 2);
    *g = (g6 << 2) | (g6 >> 4);
    *b = (b5 << 3) | (b5 >> 2);
}

// RGB8 → RGBA32 패킹 (SDL 렌더러용)
static inline uint32_t spritectl_rgb_to_rgba(uint8_t r, uint8_t g,
                                               uint8_t b, uint8_t a) {
    return (uint32_t)a<<24 | (uint32_t)b<<16 | (uint32_t)g<<8 | r;
}
```

## 4. CSprite Blt 함수 목록

각 Blt 함수는 클리핑 방향에 따라 5가지 변형을 가진다:
`Blt` / `BltClipLeft` / `BltClipRight` / `BltClipWidth` / `BltClipHeight`

| 계열 | 파라미터 | 설명 |
|------|---------|------|
| `Blt*` | - | 기본 복사 (색상키 투명 처리) |
| `BltHalf*` | - | 픽셀 밝기 50% |
| `BltAlpha*` | `BYTE alpha` | 알파 블렌딩 (0~31) |
| `BltColor*` | `BYTE rgb` | RGB 채널 조정 |
| `BltScale*` | `BYTE scale` | 확대/축소 |
| `BltDarkness*` | `BYTE DarkBits` | 어두움 처리 |
| `BltEffect*` | - | 함수 포인터 이펙트 |
| `BltColorSet*` | `WORD colorSet` | 색상 세트 교체 |
| `BltAlphaFilter*` | `CFilter*` | 알파 맵 필터 |
| `BltAlphaFilterDarkness*` | `BYTE DarkBits` | 필터 + 어두움 |
| `BltDarkerFilter*` | - | 더 어두운 필터 |
| `BltAlpha4444SmallNotTrans*` | `BYTE alpha, shift` | 4444 소형 불투명 |
| `Blt1555SmallNotTrans*` | `BYTE shift` | 1555 소형 불투명 |

## 6. CIndexSprite 색상 시스템

캐릭터 스프라이트에서 사용되는 색상 교체 시스템.

```
MAX_COLORSET_SEED       = 33   기본 색상 씨드
MAX_COLORSET_SEED_MODIFY= 15   씨드 변형 수
MAX_COLORSET            = 495  전체 색상 세트 (33 × 15)
MAX_COLORGRADATION      = 30   그라디에이션 단계
MAX_DARKBIT             = 5    어둠 단계
```

```cpp
// 색상 테이블
static WORD ColorSet[495][30];                  // 색상 세트 × 그라디에이션
static WORD ColorSetDarkness[5][495][30];       // 어둠 단계별 색상
static BYTE ColorToGradation[93];               // R+G+B → 그라디에이션 인덱스
```

**작동 원리**: 픽셀의 R+G+B 합산값으로 그라디에이션 인덱스를 구한 뒤,
현재 캐릭터의 `ColorSet` 번호에서 해당 인덱스의 색상으로 교체.
→ 같은 스프라이트로 종족/직업/장비에 따라 다른 색상 표현 가능.

```cpp
struct spritectl_pack_s {
    char*               filename;
```

## 8. TileRenderer

`MTopView`에서 타일 렌더링만 분리한 컴포넌트.

```cpp
class ITileDataProvider {          // 추상 인터페이스
    virtual int GetSpriteID(int sectorX, int sectorY) = 0;
    virtual int GetWidth() const = 0;
    virtual int GetHeight() const = 0;
};

class TileRenderer {
    bool Init(CSpriteSurface* surface, CSpritePack* spritePack);
    void SetNullTileSpritePack(CSpritePack* pack, int nullID); // 빈 타일용

    bool DrawTile(int spriteID, int screenX, int screenY, float scale=1.0f);
    void DrawTiles(ITileDataProvider*, int vpX, int vpY,
                   int vpW, int vpH, int surfX=0, int surfY=0);
    void DrawTilesNoLock(...); // 이미 Lock된 상태에서 호출용

    void ClearSurface(WORD color = 0);

```

- `DrawTiles`: 내부적으로 Lock/Unlock 처리
