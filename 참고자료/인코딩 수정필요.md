# 인코딩 수정 필요 목록

BOM 없는 UTF-8 파일을 MSVC가 현재 코드 페이지(949)로 오인식하면서, 한글
문자열/주석의 멀티바이트 시퀀스가 우연히 다른 바이트로 쪼개져 실재하지 않는
구문 오류(미선언 식별자, 문자열 리터럴 미종료, 잘못된 리터럴 접두사 등)가
발생하는 파일 목록.

같은 유형으로 이미 수정 완료된 사례: `VS_UI/src/VS_UI_GameCommon.cpp`,
`VS_UI/src/header/VS_UI_GameCommon.h` (참고자료/커밋로그/2026-08-19_VS_UI_GameCommon_UTF8_BOM_추가.md)

## 수정 완료 (2026-08-20, BOM 추가)

아래 4개 파일 모두 BOM만 추가(내용 변경 없음)하여 해결됨. 자세한 내용은
`참고자료/커밋로그/2026-08-20_WinMain_RenderingFunctions_UtilityFunction_FL2_UTF8_BOM_추가.md`
참고.

- `dk_client/VS_UI/WinMain.cpp` - 1601~2679줄대 한글 문자열 리터럴 관련
  `C2001`/`C3680`/`C3688` 오류 전부 해소됨
  - 참고: 같은 파일 3201줄대 이후의 `FILE_INFO_*`/`SPK_*` 미선언,
    `ifstream`이 `WinMain::ifstream`으로 오인식되는 오류들은 BOM 추가 후에도
    그대로 남아 있어, 인코딩 문제의 연쇄 효과가 **아니라 별개의 독립적인
    버그**로 확인됨 (이전 기록의 추측을 정정)
- `dk_client/Client/RenderingFunctions.cpp` - 414/419줄 한자 포함 문자열
  리터럴 관련 `C2001` 오류 해소됨. 단, 같은 파일의 62/67줄
  `S_SURFACEINFO` 미선언 등은 인코딩과 무관한 별개 오류로 남아있음
- `dk_client/Client/UtilityFunction.cpp` - 234줄 한글 자모 문자열 리터럴
  관련 `C2001` 오류 완전히 해소됨 (이 파일은 다른 오류 없이 전부 해결)
- `dk_client/VS_UI/src/hangul/FL2.cpp` - 578/587줄 한글 포함 문자열
  리터럴 관련 `C2001` 오류 해소됨. 단, 같은 파일의 230/342/359줄
  (`'c'` 미선언, `IDirectDrawSurface` 미정의)은 인코딩과 무관한 별개
  오류로 남아있음
