# 커밋 로그 (실제 커밋은 이미 반영됨 - 아래는 기록용 요약)

- 일시: 2026-08-18
- 대상: `Client/SpriteLib/CMakeLists.txt`
- 유형: fix (링커 경고 수정, SpriteLib LNK4006)

## 커밋 메시지

```
fix: SpriteLib CMakeLists.txt에서 CSpriteSurface_Adapter.cpp 중복 컴파일 제거

CSpriteSurface_Adapter.cpp는 파일 상단 주석에 명시된 대로
"Do not compile separately" 원칙에 따라 CSpriteSurface_SDL.cpp(411줄)에서
#include로 소스 텍스트째 포함되는 파일인데, CMakeLists.txt의
SPRITELIB_SOURCES 목록에도 별도 소스로 등록되어 있어 두 번 컴파일되고
있었음. 그 결과 CSpriteSurface::Blt* 계열 멤버 함수가
CSpriteSurface_SDL.obj와 CSpriteSurface_Adapter.obj 양쪽에 정의되어
링크 시 LNK4006(중복 정의, 한쪽 무시) 경고가 다수 발생.

SPRITELIB_SOURCES 목록에서 CSpriteSurface_Adapter.cpp 항목을 제거하여
CSpriteSurface_SDL.cpp를 통한 단일 컴파일만 남김.
```

- `cmake .` (build/vs2019 재구성) → `SpriteLib.vcxproj`에서 `CSpriteSurface_Adapter.cpp` ClCompile 항목 사라짐 확인
- `MSBuild build/vs2019/Client/SpriteLib/SpriteLib.vcxproj /p:Configuration=Debug /p:Platform=x64 /t:Rebuild`
- 수정 전: `LNK4006` 경고 다수 (`CSpriteSurface::Blt*` 계열 함수들이 `CSpriteSurface_Adapter.obj`에 이미 정의되어 있다는 경고)
- 수정 후: `LNK4006` 경고 0건, `SpriteLib.lib` 빌드 성공 (exit code 0)
