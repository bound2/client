# 분석 제외 파일 목록

분석 대상에서 제외할 파일 확장자 및 파일 목록 (filelist.txt 기반)

---

## 제외 확장자

| 확장자 | 분류 | 사유 |
|--------|------|------|
| `.ico` | 아이콘 바이너리 | 이미지 리소스, 코드 아님 |
| `.bat` | 배치 스크립트 | 빌드 유틸리티, 분석 대상 외 |
| `.bak` | 백업 파일 | 구버전 소스 스냅샷 |
| `.htm` | HTML 로그 | 업그레이드 로그 문서 |
| `.vcxproj` | VS 프로젝트 | IDE 자동 생성 |
| `.vcxproj.filters` | VS 필터 | IDE 자동 생성 |
| `.vcxproj.user` | VS 사용자 설정 | IDE 자동 생성 |
| `.rc` | 리소스 스크립트 | Windows 리소스 컴파일러 입력 |
