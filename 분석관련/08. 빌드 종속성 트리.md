## 내부 라이브러리 계층

```
레이어 0 (외부 라이브러리)
├── SDL2::SDL2
├── SDL2::SDL2main
├── SDL2_image::SDL2_image
├── SDL2_ttf::SDL2_ttf          ← freetype2 포함
└── SDL2_mixer::SDL2_mixer      ← libogg, libvorbis, wavpack 포함

레이어 1 (플랫폼 추상화)
└── basic                       ← Platform.h, Typedef.h, PlatformUtil.h
    └── SDL2::SDL2

레이어 2 (하드웨어 래퍼)
├── dxlib                       ← DirectX → SDL2 래퍼
│   ├── basic
│   ├── SDL2::SDL2
│   └── SDL2_mixer::SDL2_mixer
└── SpriteLib                   ← 스프라이트 렌더링
    ├── basic
    ├── dxlib  (헤더만)
    └── SDL2::SDL2

레이어 3 (엔진 서브시스템)
├── framelib                    ← 프레임/애니메이션
│   ├── basic
│   └── SpriteLib
└── TextSystem                  ← 텍스트 렌더링
    ├── SpriteLib
    ├── SDL2::SDL2
    └── SDL2_ttf::SDL2_ttf

레이어 4 (UI 및 게임 로직)
└── VS_UI                       ← UI 프레임워크 + 게임 로직 일부
    ├── basic
    ├── dxlib
    ├── SpriteLib
    ├── framelib
    ├── TextSystem
    ├── SDL2::SDL2
    ├── SDL2::SDL2main
    ├── SDL2_image::SDL2_image
    └── SDL2_ttf::SDL2_ttf

레이어 5 (최종 실행파일)
└── DarkEden
    ├── VS_UI   (레이어 4 전체 포함)
    ├── SpriteLib
    ├── dxlib
    ├── basic
    ├── framelib
    ├── TextSystem
    └── SDL2::SDL2, SDL2::SDL2main
```

## 외부 패키지 상세

| 패키지 | 버전 (vcpkg) | 용도 | 필수 |
|--------|-------------|------|------|
| SDL2 | 2.32.10 | 창 생성, 이벤트, 렌더링 기반 | ✅ |
| SDL2_image | 2.8.12 | 이미지 파일 로딩 (PNG 등) | ✅ |
| SDL2_ttf | 2.24.0 | 트루타입 폰트 렌더링 (freetype2 내장) | ✅ |
| SDL2_mixer | 2.8.2 | 효과음/배경음악 재생 | ✅ |
| freetype2 | (SDL2_ttf 내장) | 폰트 글리프 렌더링 | (자동) |
| libogg | 1.3.6 | OGG 컨테이너 (SDL2_mixer 내장) | (자동) |
| libvorbis | 1.3.7 | Vorbis 오디오 디코더 | (자동) |
| wavpack | 5.9.0 | WavPack 오디오 디코더 | (자동) |
| libpng | 1.6.58 | PNG 디코더 (SDL2_image 내장) | (자동) |
| zlib | 1.3.2 | 압축 (PNG/일반) | (자동) |
| brotli | 1.2.0 | freetype2 압축 지원 | (자동) |
| bzip2 | 1.0.8 | freetype2 압축 지원 | (자동) |
| libjpeg | — | JPG 로딩 (미설치, 선택사항) | ❌ |
| libiconv | — | 문자셋 변환 (WIN32 제외됨) | ❌ |
